# Intent

Slice S2 of the strangler series migrates the periphery off the jquery wrapper — `dom` and `idle` go native, the IE8-only
`jquery__event_type_winresize` block is deleted, the legacy ym-style benchmark blocks are replaced by a Playwright bench
project (B1–B5) whose ratio-to-v5-base gate fires for the first time at this slice's done-gate — and lands the internal
DOM facade leg of the i-bem-dom decomposition (scripts-inert `parseHtml`, KC 3/6/11/12, D-11). Zero i-bem-dom internals
migrate (S4/S5).

# Behavior

## REQ-1 (add): parseHtml escape-hatch audit — GO for scripts-inert

- Evidence: `common.blocks/i-bem-dom/i-bem-dom.js:285 :: getJqueryCollection :: "    if(typeof html === 'string') return $($.parseHTML(html, null, true))"`

Named audit (D-11), pattern and result quoted here: `grep -rn "parseHTML\|parseHtml" --include='*.js' common.blocks
desktop.blocks touch.blocks test build` → exactly one hit (the cited line, keepScripts=true); `grep -rn '<script'
--include='*.js' common.blocks test` → zero spec/source fixtures feeding scripts through bemDom content APIs. Result:
**GO** — no script-execution dependent exists, `dom.parseHtml` is scripts-inert (script elements are not returned;
documented C4 break, MIGRATION S2). Had a dependent existed, this REQ would have reverted to parity (template parse +
script re-creation) inside S2.

## REQ-2 (change): internal DOM facade + native `dom`

- Evidence: `common.blocks/dom/dom.js:6 :: dom :: "import $ from 'bem:jquery'"`
- Evidence: `common.blocks/i-bem-dom/i-bem-dom.js:15 :: dom :: "import dom from 'bem:dom'"`
- Evidence: `common.blocks/i-bem-dom/i-bem-dom.js:741 :: contains :: "        return dom.contains(this.domElem, entity.domElem)"`
- Evidence: `build/barrel.js:15 :: dom :: "export { default as dom } from 'bem:dom';"`

`dom.js` is rewritten native (no jquery import; `dom.deps.js` deleted — no deps remain). Facade contract: helpers accept
a native node or any array-like collection (jQuery collections included — iterated by index, never wrapped); inputs and
outputs are native nodes (`getFocused` returns `Element|null`, was jQuery — API delta, MIGRATION S2). `parseHtml(html)`
is added to the public `dom` surface — the only sanctioned HTML-string entry point: parses via a template element,
never returns script elements (REQ-1 GO). `i-bem-dom` string parsing routes through it:
`getJqueryCollection` wraps `$(dom.parseHtml(html))`; `i-bem-dom.js:741` keeps working unchanged via collection
tolerance. The facade stays inside the `bem:dom` module graph — no merge into i-bem-dom internals (KC 6 progressive leg).
