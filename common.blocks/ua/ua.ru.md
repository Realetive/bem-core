# ua

Блок служит для сбора данных о браузере пользователя.

> **Устарел с 6.0.0**: JS-модуль `ua` — теперь алиас нового модуля [`env`](../env/env.ru.md) на один релиз; в следующем релизе он удаляется — мигрируйте на `env`.

## Алиас модуля ua

`bem:ua` живо проксирует чтения свойств в модуль `env`: `ua`, `platform`, `ios`, `android`, `bada`, `wp`, `other`, `browser`, `opera`, `chrome`, `screenSize`, `svg`, `width`, `height`, `landscape`. Особенности:

- **Удалённые поля** — `msie`, `webkit`, `safari`, `mozilla`, `version`, `iphone`, `ipad`, `dpr`, `flash`, `connection`, `video` — предупреждают один раз на поле (через `console.warn`) и возвращают `undefined`; любое другое непроксируемое поле ведёт себя так же.
- **Присваивания** предупреждают один раз и игнорируются.
- **Контракт — только чтение свойств**: деструктуризация и спред-снапшоты не поддерживаются — значения живые.

```js
// раньше
import ua from 'bem:ua';
if(ua.msie) { /* ... */ }
// теперь
import env from 'bem:env';
if(env.platform.ios) { /* ... */ }
```

## Описание

Блок подключает инлайновый скрипт, добавляющий тегу `<html>` `CSS`-классы, указывающие, включен ли JavaScript – `ua_js_no`/`ua_js_yes`.

Не имеет визуального представления на странице.

Используется внутри блока [page](https://github.com/bem/bem-core/blob/v2/common.blocks/page/page.ru.md) и самостоятельно подключать его к странице обычно не требуется.

### Элементы блока

<a name="elems-svg"></a>

#### Элемент `svg`

Элемент подключает инлайновый скрипт, добавляющий тегу `<html>` `CSS`-классы, указывающие, поддерживается ли SVG – `ua_svg_no`/`ua_svg_yes`.

Не имеет визуального представления на странице.

Для использования включите элемент в файл зависимостей `deps.js` блока, которому требуются данные о поддержке SVG:

```js
({ shouldDeps : { block : 'ua', elem : 'svg' } })
```
