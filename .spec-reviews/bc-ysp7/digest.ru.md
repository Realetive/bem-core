# Дайджест: S0 — предохранительный забор верификации и публичные контракты (первый срез strangler-серии arch-overhaul)

## Срез: что меняем и зачем

Архитектура форка осталась дизайном 2016 года: jQuery-обёртка как DOM-основа за ракеткой из 9 вхождений,
непроверяемые границы платформенных слоёв и отсутствие машинно-проверяемого публичного API — при уже
современном тулчейне (Vite 8, ESM). Срез S0 ставит «забор» (гейт размера бандла, предикаты конституции,
док-фенс, генерация платформенных входов) и публичные контракты (barrel, карта exports, API-pin) — фундамент,
на который опираются гейты всех последующих срезов. Поведение библиотеки не меняется, кроме двух
задокументированных ломок поверхности экспорта (корень `.` и сужение `"./*"`).

## Приёмка

22 ACC, каждая — одна исполняемая команда с явным ожиданием: `npm test` (api-pin, gate-fixtures), сборка +
`node build/check-bundle-size.mjs`, `node build/check-doc-parity.mjs`, `bash specs/check-platform-baseline.sh`,
`bash specs/check-jquery-ratchet.sh`, свежесть `build/platforms/*.gen.js` через `git diff --exit-code`,
паритет payload против `specs/pre-s0-platforms-*.txt`, `npm run lint`, отсутствие секретов в specs/.

## Чего НЕ делаем в этом срезе (Non-goals)

- Нет tree-shaking сверх истории плагина; нет TypeScript; нет новых блоков и дополнений публичного API.
- Нет редизайна шаблонов/BEMJSON и ре-синка с апстримом (жёсткий форк по CONST-P5).
- `inherit` заморожен (ноль изменений кода), внутренности `keyboard` заморожены (`keyboard__codes` переживает
  генерацию дословно).
- Нет линта схемы `.deps.js`, бенчей (S2) и унификации конвертеров (S6); исходы S1–S6 вне области спеки.
